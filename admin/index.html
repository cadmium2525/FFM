GitHubリポジトリへ接続

対象リポジトリへの書き込み権限を持つ Personal Access Token (classic か fine-grained、 repo スコープ) を入力してください。トークンはこのブラウザの localStorage にのみ保存され、GitHub API (api.github.com) 以外へは送信されません。次回以降このブラウザ からアクセスした際は自動的に再接続されます。

    左のリストからボスを選択するか、新規ボスを作成してください。

      左のリストからステージを選択するか、新規ステージを作成してください。

      変更内容の確認

      コミット後、GitHub Actionsがゲーム側の反映用ファイル(.jsミラー / app.js / index.html)を 自動的に再生成してコミットします。実際にゲームへ反映されるまで数分かかる場合があります。
